2. Supported products & wiring

This tester can be used with these ELECHOUSE PN532 products:

  • PN532 NFC RFID Module V4
  • PN5321 MINI / PN532 Mini
  • PN532 NFC USB Module
  • PN532 NFC Evolution V1

TTL note: ELECHOUSE PN532 UART/HSU pins are compatible with both 3.3V and 5V TTL USB-to-TTL adapters.

  • PN532 NFC RFID Module V4: switch the module to UART / HSU mode, then connect USB-TTL TX → PN532 RX, USB-TTL RX → PN532 TX, GND → GND, and power the board from 3.3V or 5V.
  • PN5321 MINI / PN532 Mini: set the solder pads/jumpers to UART / HSU mode, connect USB-TTL TX → RX, RX → TX, share GND, and power the board from the adapter or another stable 3.3V/5V supply.
  • PN532 NFC USB Module: connect the module directly to the computer with USB-C and select its virtual serial/COM port in the browser. No external USB-TTL adapter is required.
  • PN532 NFC Evolution V1: switch the main board to UART / HSU mode, connect USB-TTL TX → HSU RX, RX → HSU TX, share GND, power the board from 3.3V or 5V, and make sure the external antenna board is connected before testing.
  • Open this page from HTTPS or localhost.

3. Poll ISO14443A card

Place a card near the antenna, then start polling. The demo sends PN532 InListPassiveTarget commands and displays the UID.
